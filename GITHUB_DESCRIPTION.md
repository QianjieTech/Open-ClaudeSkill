Hi r/[relevant-subreddit]!

I've been working on **Open-ClaudeSkill**, an open-source MCP server that implements Claude's skill system for any MCP-compatible AI agent.

## What is it?

It's a progressive disclosure system that lets you add specialized capabilities to AI agents without loading everything into context at once. Skills are listed with brief descriptions, and full content is only loaded when actually needed.

## Why build this?

Claude Code has this great skill system, but it's proprietary. I wanted to make it available to the wider AI agent ecosystem - Kilo Code, Claude Desktop, Cline, Continue.dev, etc.

## Key Features:

- ✅ **Progressive Disclosure**: Save context by loading skills on-demand
- ✅ **Universal**: Works with any MCP-compatible agent
- ✅ **Standard Format**: 100% compatible with official Claude Skills
- ✅ **Hot-Reload**: Updates automatically when you modify skills
- ✅ **Easy Setup**: One-command installation via uvx

## Tech Stack:

- Python 3.10+
- MCP (Model Context Protocol)
- YAML + Markdown for skill definitions
- Watchdog for file monitoring

## Example Use Cases:

- Code review with security focus
- Mathematical calculations with explanation
- Domain-specific knowledge bases
- Custom workflows and best practices
